# ЗАЛЁТ — игра про кейсы для компании друзей

Браузерная онлайн-игра: открытие кейсов, апгрейдер, контракты, батлы, коинфлип, общий «Краш», батл-пасс, «Час залёта» (x2 XP по таймеру). Валюта только игровая: никаких реальных денег, доната и вывода. Интерфейс на русском, работает на ПК и телефоне.

- Клиент: Vite, React, TypeScript, Zustand, Framer Motion, three.js, Howler.
- Сервер: Supabase (Postgres). Все операции с монетами делает сервер через функции (RPC), клиент только просит и показывает анимацию.
- Честность: server seed (хеш виден заранее) + client seed + nonce → HMAC-SHA256. Страница «Честность» перепроверяет любой дроп.
- Все цифры экономики в одном файле: `src/config/economy.ts`.

## Быстрый старт (локально, без облака)

Нужны Node 22+ и локальный Postgres 16 (в нём пользователь `postgres` с паролем `postgres`, или задай `DEV_PG_URL`).

```bash
npm install
npm run stack        # локальный «мини-Supabase» на :54321
npm run dev:stack    # клиент на :5173, в другом терминале
```

Так игра работает без интернета и без аккаунта Supabase. Для настоящей игры с друзьями нужен Supabase (ниже).

## Как создать проект Supabase (бесплатно, 5 минут)

1. Зайди на [supabase.com](https://supabase.com), создай аккаунт и новый проект (тариф Free). Запомни пароль базы, он не понадобится в игре.
2. Открой **SQL Editor**, вставь целиком содержимое `supabase/schema.sql` и нажми **Run**.
3. Там же вставь и запусти `supabase/seed.sql` (кейсы и экономика). Если менял `src/config/economy.ts`, сначала выполни `npm run gen:sql`, он пересоберёт этот файл.
4. **Authentication → Sign In / Providers**: включи **Allow anonymous sign-ins**.
5. **Project Settings → API**: скопируй **Project URL** и **anon public key**.
6. Скопируй `.env.example` в `.env` и вставь значения:

   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJ...
   ```

   Файл `.env` не попадает в git. Ключ `anon` публичный по замыслу Supabase: безопасность держится на правах таблиц (RLS) и на том, что денежные функции работают только на сервере. Ключ `service_role` в игру не вставляй никогда.
7. `npm run dev` для проверки, `npm run build` для сборки.

Если ты менял экономику после запуска: клиент сравнивает версию конфига с сервером и покажет красный баннер, пока не перезальёшь свежий `seed.sql`.

## Деплой

### GitHub Pages (готовый workflow в `.github/workflows/deploy.yml`)

1. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. **Settings → Secrets and variables → Actions → New repository secret**: добавь `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
3. Запушь в ветку `main` (или запусти workflow вручную во вкладке Actions). Через пару минут игра откроется по адресу `https://<ник>.github.io/<репозиторий>/`.

Маршруты на хеше (`/#/case/...`), поэтому отдельная настройка серверных редиректов не нужна.

### Vercel

Импортируй репозиторий, в **Environment Variables** добавь те же две переменные, команда сборки `npm run build`, папка `dist`.

## Как пригласить друзей

Просто отправь ссылку на игру. Каждый вводит свой ник и PIN: новый ник создаёт профиль, а чужой ник без PIN не открыть. С другого устройства заходят тем же ником и PIN. Приватный батл или коинфлип можно кинуть ссылкой из комнаты («Ссылка»).

## Где крутить цифры

Всё в `src/config/economy.ts`: шансы и стоимость редкостей, цена и RTP каждого кейса, апгрейдер, контракты, бонусы, батл-пасс, задания, достижения, промокоды (список `PROMO_CODES`).

После правок:

```bash
npm run simulate   # RTP каждого кейса на 1 000 000 открытий и симуляция «вечера»; падает, если RTP ушёл больше чем на 1 %
npm run gen:sql    # пересобрать supabase/seed.sql, затем залить его в Supabase
```

## Тесты и проверки

```bash
npm test           # Vitest: рулетка, шансы, апгрейдер, контракты, батлы, честность
npm run test:db    # серверная логика на локальном Postgres (права, деньги, гонки, батлы, бонусы)
npm run e2e        # Playwright на 375 и 1440 px со скриншотами в e2e/shots
```

## 3D-модели

Оружие, ножи и перчатки это настоящие 3D-модели с Sketchfab под лицензиями CC-BY и CC0. Авторы перечислены в `CREDITS.md` и на странице «Авторы моделей» в игре. Скины накладываются на них процедурно прямо в шейдере. Подготовка файлов (сжатие, удаление лишнего): `node scripts/models/prepare.mjs <папка с исходниками>`.

## Структура

```
src/config/        экономика, контент кейсов
src/shared/        логика, общая для клиента и проверки (ролл, апгрейд, контракт, батл, честность)
src/art/           3D-рендер предметов и кейсов, скины
src/pages, src/components, src/store, src/audio   интерфейс
supabase/          schema.sql (таблицы, права, функции), seed.sql (генерируется)
scripts/           simulate, gen-sql, devstack (локальный Supabase), models (подготовка моделей)
tests/, e2e/       Vitest, Playwright
```
